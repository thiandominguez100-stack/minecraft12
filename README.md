# BlockWorld 3D

A small original browser-based voxel sandbox prototype.

## Run
Open the repository with GitHub Pages:
1. In GitHub, open **Settings → Pages**.
2. Select **Deploy from a branch**.
3. Choose branch **main** and folder **/(root)**.
4. Save, then wait for the Pages deployment.

## Controls
- WASD: move
- Mouse: look around
- Left click: break a block
- Right click: place the selected block
- 1–9: select hotbar slot
- E: inventory
- T: command console
- Space: jump in Survival; fly upward in Creative
- Shift: fly downward in Creative
- Esc: release the mouse

## Commands
- `/help`
- `/gamemode creative` or `/gamemode survival`
- `/give stone 64` (block IDs: grass, dirt, stone, wood, leaves, sand, water, planks, brick, glass, cobble, bedrock, gold, diamond, torch)
- `/time set day` or `/time set night`
- `/weather clear` or `/weather rain`
- `/tp 0 10 0`
- `/clear`

## Notes
This is an original prototype, not a copy of Minecraft. It uses original interface code and simple colored voxel materials. It currently includes a generated test landscape, basic block placement/mining, a hotbar, a categorized item picker, Creative/Survival modes, and a small command set. It does not yet implement the full Minecraft item catalog, crafting, mobs, redstone, multiplayer, or full survival simulation.
